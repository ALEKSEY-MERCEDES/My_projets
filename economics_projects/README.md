## Краткое описание проектов

**Микроэкономика. Практика 1** — задачи на агрегирование индивидуального спроса, нахождение оптимальной цены монополиста и визуализация функции спроса.

**Микроэкономика. Практика 2** — применение теории игр к реальным данным: построение матриц выигрышей для пенальтистов на основе статистики ударов, поиск равновесия Нэша в смешанных стратегиях.

**Social Choice Theory** — исследование манипулируемости 7 правил голосования (Борда, Плюральность, Кондорсе и др.). Реализованы индексы Келли и Алескерова–Курбанова. Отдельный раздел — эксперимент с LLM (Claude) в роли стратегического агента голосования.

**Практика по экономике** — командный анализ данных RLMS (Российский мониторинг экономического положения и здоровья населения) за 2014 и 2023 годы. Тема: межпоколенческая мобильность, связь образования и дохода родителей и детей.

**Data Analysis (Excel)** — анализ финансовых данных с помощью Power Query: загрузка, трансформация и агрегация данных без написания кода.
