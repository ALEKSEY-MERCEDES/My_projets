Репозиторий с учебными и личными проектами по машинному обучению, анализу данных и экономике. Материалы проектов находятся в соответствующих папках.

## Структура

### 🤖 [Recommender systems in finance](./Recommender-systems-in-finance/)
Курсовой проект: рекомендательные системы для задачи инвестор–актив на датасете FAR-Trans. Сравнение 11 моделей, лучший результат — гибридная модель Hybrid Rank Fusion

### 💻 [Practice Notebooks](./practice_notebooks/)
Практические домашние задания курса «Машинное обучение» (ФКН ВШЭ): градиентный спуск, деревья решений, бустинг, нейронные сети, feature engineering

### 📊 [Financial Analysis](./financial%20analysis/)
Командный проект: анализ финансовой отчётности ПАО «Аэрофлот» и сравнение с конкурентами за 2020–2024 гг. (ЮТэйр, Turkish Airlines).

### 📈 [Economics Projects](./economics_projects/)
Учебные проекты по микроэкономике и анализу данных: теория игр, теория коллективного выбора, анализ RLMS, Power Query.

### [A/B-тесты](./A-B-tests/)
Учебная работа по планированию A/B-эксперимента: расчёт размера выборки, сравнение вариантов распределения участников и правила мониторинга.

### [Прогнозирование денежных потоков](./Cash-flow-forecasting/)
Индивидуальный проект для конкурса «АСВ: лидеры будущего» по оценке и прогнозированию денежных потоков от работы с проблемными активами кредитных организаций.
