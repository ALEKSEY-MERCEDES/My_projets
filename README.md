## Структура

Курсовой проект: рекомендательные системы для задачи инвестор–актив на датасете FAR-Trans. Сравнение 11 моделей, лучший результат — соя гибридная модель Hybrid Rank Fusion

Практические домашние задания курса «Машинное обучение» (ФКН ВШЭ): градиентный спуск, деревья решений, бустинг, нейронные сети, feature engineering

### 📊 [Financial Analysis](./financial_analysis/)
Командный проект: анализ финансовой отчётности ПАО «Аэрофлот» и сравнение с конкурентами за 2020–2024 гг. (ЮТэйр, Turkish Airlines).

### 📈 [Economics Projects](./economics_projects/)
Учебные проекты по микроэкономике и анализу данных: теория игр, теория коллективного выбора, анализ RLMS, Power Query.
